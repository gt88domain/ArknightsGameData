# 百妖灯阵（Lantern Array）生产化执行计划

> 状态：原型已完成，尚未进入生产化打磨。  
> 基线：`arena/01a08b63-arknightsgamedata`，计划创建前 exact head `6e50a76c09ed2125a282a1d7bd4710be0a527dcb`。  
> 目标：把当前 18 关原型收敛为一款 **12–18 分钟一局、5 秒进入战斗、30 秒内形成连续反馈、完全离线、可重复游玩的原创塔防 Roguelite 单机**。  
> 边界：继续使用 `ArknightsGameData` 作为离线统计/结构参考；运行时只读取百妖灯阵自己的归一化 schema。不得把原作角色名、敌名、剧情、Logo、美术或原始大表直接带入游戏。

## 0. 产品定义与成功标准

一句话：**快速布阵 → 密集妖潮 → 自动技能连锁 → 每关一次构筑选择 → 阵容逐渐失控变强 → 三个 Boss 检验 Build → 立即重开换套路。**

默认模式不是复杂关卡解谜，也不是手游养成。第一版成功标准只有四项：

1. **快**：首次进入游戏到第一只敌人出现 ≤ 5 秒；关间选择通常 ≤ 6 秒；默认完整 run 12–18 分钟。
2. **爽**：首 30 秒至少出现部署、击杀、技能/特效、资源增长四类反馈；中后段敌群密度和 Build 强度都明显上升。
3. **可读**：玩家不读长教程也能理解“放谁、放哪、现在危险不危险、刚才为什么变强”。
4. **想重开**：同一玩家连续 3 局能形成明显不同的构筑方向，而不是只有数值大小不同。

### 发布级 V1 内容预算

- 7 职业。
- 21 个“真正有差异”的核心灯灵；现有 42 个全部保留，但其余 21 个可先作为扩展/数值型角色，后续再差异化。
- 普通敌人 16–20、精英 8、Boss 3（第 4/8/12 关，其中第 12 为终局 Boss）。
- 8–12 个原创地图模板。
- 36–45 件法器，至少形成 8 种可辨认 Build。
- 12–16 个短事件。
- 普通 / 苦夜 / 无明 3 难度。
- 通关后解锁 Endless。
- 本地图鉴、设置、成就、统计、版本化存档。

## 3. P1：快节奏爽感 Vertical Slice（第一轮真正的产品化）

**P1 的目标不是“内容更多”，而是让一局好玩。**

### P1-1 默认 run 从 18 关收敛为 12 关

默认结构：

1. 普通
2. 普通
3. 精英
4. Boss 1
5. 普通
6. 异变
7. 精英
8. Boss 2
9. 普通
10. 异变
11. 精英
12. Final Boss

时长目标：

- 普通关 45–60 秒。
- 精英关 60–75 秒。
- Boss 70–100 秒。
- 关间选择 3–6 秒。
- 一局 12–18 分钟。

旧 18 关曲线可以后续作为长夜/Endless 前置模式，不删除历史数据，但默认 UI 不再以 18 关为核心。

### P1-2 快速开局

- [ ] 标题页主 CTA 为“开始夜巡”。
- [ ] 使用上次编队；首次自动给 7 职业各 1 个的可用队伍。
- [ ] 点击开始后 ≤ 5 秒第一只敌人出现。
- [ ] 新玩家教学使用 2–3 个短提示覆盖部署/费用/危险，不做多页强制教程。

### P1-3 灯阵共鸣（唯一主动大招）

- [ ] 击杀/战斗行为积累共鸣槽。
- [ ] 满槽出现一个清晰的全局按钮。
- [ ] 释放：全场可读的大范围伤害 + 短暂减速（具体数值先简单）。
- [ ] 不增加每个单位的手动技能按钮；单位技能继续自动释放。
- [ ] Boss 战中共鸣不能一键跳过 Boss 机制，数值有上限。

验收：第一次普通关中，新手平均能看到至少一次共鸣；按钮与效果无需教程也能理解。

### P1-4 击杀链与反馈

- [ ] 5/10/20/30 kill streak 分级视觉/音频反馈。
- [ ] 连杀只给轻量资源/SP 奖励，不能成为第二套复杂经济系统。
- [ ] 命中、击杀、暴击/重击、技能、Boss 入场具有不同层级反馈。
- [ ] 支持 Reduced Motion；关闭/降低屏幕震动不影响信息可读性。

### P1-5 敌潮密度而非纯血量膨胀

- [ ] 第一幕清楚简单；第二幕加入双路/飞行/冲锋；第三幕明显增加同屏敌人数与精英混编。
- [ ] 后期难度增长至少一半来自组合与数量，而不是单纯 HP × N。
- [ ] 性能 Gate：目标设备同屏 40+ 敌人 + 8–12 灯灵 + 粒子时仍可稳定游玩；具体 FPS 用浏览器 profile 记录。

### P1-6 三个容易读懂的 Boss

- Boss 1：冲阵；检验阻挡。
- Boss 2：召唤；制造小怪潮。
- Final Boss：两阶段，50% HP 后变暗/攻速提升/持续召唤。

每个 Boss 第一版只保留 1 个核心记忆点，禁止堆 5–10 个机制。

### P1 验收 Gate

自动：

- [ ] P0 全部继续通过。
- [ ] 12 关固定 seed 至少 20 个模拟样本，无死循环/卡关。
- [ ] Boss 1/2/Final 都有确定性测试。
- [ ] 共鸣不能导致负数、重复结算或已死亡敌人二次奖励。

浏览器：

- [ ] Desktop：Chrome/Edge 最新稳定版一局完整可玩。
- [ ] Mobile viewport：触屏热区 ≥ 44px，不出现关键按钮被遮挡。
- [ ] 1x / 2x / 3x 倍速行为一致。
- [ ] 暂停恢复无时间跳跃。
- [ ] 从点“开始夜巡”到首敌 ≤ 5 秒。
- [ ] 普通 run 真实游玩时长 12–18 分钟（记录 3 局）。

## 4. P2：构筑深度（P1 好玩以后才做）

### 法器目标

从现有 28 件扩至 36–45 件，但优先把“+15% 数值”升级为可辨认机制。

Build tags：

- `economy` 疾风/灯油
- `block` 镇石/阻挡
- `physical` 破阵
- `ranged` 远影
- `magic` 咒焰
- `heal` 回辉
- `aura` 祝言
- `death` 阵亡/爆炸
- `mixed` 多职业
- `risk` 高风险高收益

示例质变法器：

- 风眼：疾风攻击额外产油；油接近上限时全队获得攻速。
- 赤莲：咒术击杀产生小范围爆炸。
- 穿云：远影每第 N 次攻击产生穿透。
- 不灭灯：过量治疗转护盾。
- 七灯阵：场上存在 ≥5 个不同职业时获得团队增益。

### P2 Gate

- [ ] 至少 8 个 Build 在规则上可辨认，而不是只靠数值名义分类。
- [ ] 连续 30 个固定 seed run 中，不出现某一法器/职业选择率接近 100% 的显然必选项。
- [ ] 至少 3 种不同 Build 能在普通难度通关。
- [ ] 法器选择、reroll、重复保护均有测试。

## 5. P3：角色差异化

不先重做 42 个。优先 21 个核心灯灵：7 职业 × 3 种玩法。

验收标准：隐藏名字与头像，只看攻击方式/技能效果，玩家仍能区分同职业的三个核心角色。

示例：

- 咒焰：持续灼烧 / AOE 爆发 / 高费超级炮台。
- 镇石：纯坦 / 反伤 / 群控。
- 远影：高攻速 / 爆击 / 穿透。

其余 21 个可继续作为轻量扩展角色，避免一次性内容爆炸。

### P3 Gate

- [ ] 21 个核心角色每个有独立 mechanic tag。
- [ ] 不出现角色技能“只换名字、只改 +X%”的伪差异化。
- [ ] 每职业至少 2 个角色在普通难度有可行构筑。

## 6. P4：从 ArknightsGameData 继续提取“结构”，不复制内容

`normalize.py` 后续可以研究更多公开数据，但只输出匿名统计/原创 archetype：

- 敌人：速度、质量、护甲、射程、飞行、召唤、冲锋等分布。
- Wave：每波数量、间隔、质量预算、精英比例、Boss 前后节奏。
- Map：路线数、长度、交叉点、瓶颈、入口/出口数量、高低台比例等统计。
- Skills/Buffs：触发方式与效果类别分布。
- Roguelike：奖励频率、稀有度、事件/收藏品作用类别。

禁止：运行时加载原始表；复制原名、文本、剧情、地图布局、角色/敌人视觉；以“还原原作”为验收目标。

### P4 地图目标

- 8–12 个原创基础模板。
- 每局通过入口/出口、禁用格、增益格、妖气格、路线组合做轻变化。
- 地图变化服务于部署抉择，不做大量一次性手工谜题图。
