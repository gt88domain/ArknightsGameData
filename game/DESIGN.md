# 百妖灯阵 · 设计文档（Lantern Array）

原创 HTML5 塔防 + 肉鸽。数据仅参考公开数据集 `gt88domain/ArknightsGameData`
的**结构与数值曲线**（职业分类 / 1–6★ 属性曲线 / 技能触发与效果类别 /
敌种原型 / 波次构成 / 肉鸽系统），**不使用任何原作名称、角色、剧情、logo 或美术**：
世界观、阵营、单位名、法器名、敌名全部原创，画面为 Canvas 矢量/几何风。

---

## 1. 世界观与阵营

- 世界观：大灯破碎，「浊潮」自裂隙涌出，要将人间灯火尽数熄灭。
- 玩家：**执灯人**（阵营「灯阵」），布下百妖灯阵。
- 敌人：**浊妖**（浊潮凝聚：基本 / 精英 / 首领三档，地面 / 飞行两种机动）。
- 资源：**灯油**（部署费用，时间恢复 + 击杀 + 疾风类攻击产出）；
  **灯心**（基地血量）；**残焰**（跨局元货币）。

## 2. 职业系统（7 职业 × 6★，共 42 灯灵）

职业分类与 1–6★ 属性曲线抽取自参考数据 `character_table.json`
（按 profession × rarity 分组，取 level-1 属性均值并平滑为单调曲线），
每个（职业, ★）单元生成 1 名原创灯灵。

| 职业 | 映射参考 | 定位 | 1★生/攻/油 → 6★生/攻/油 |
|---|---|---|---|
| 疾风 RUNNER | 先锋 | 轻量突进，攻击产油（被动火花） | 510/104/3 → 858/224/19 |
| 镇石 GUARD | 重装 | 灯道阻挡（阻挡2），嘲讽技 | 921/158/3 → 1487/292/19 |
| 破阵 WARRIOR | 战士 | 近身强攻，反击/溅射 | 816/208/3 → 1375/347/19 |
| 远影 SHOOTER | 狙击 | 远距单体物理，可打飞行 | 405/178/3 → 821/358/19 |
| 咒焰 WITCH | 术师 | 咒术群伤/无视防御，可打飞行 | 393/182/3 → 1235/364/19 |
| 回辉 MEDIC | 医疗 | 范围治疗（4s 跳 + 群疗技） | 261/42/3 → 850/174/19 |
| 祝言 CHANT | 支援 | 光环（攻/攻速/生命） | 282/107/3 → 660/208/19 |

- 只有 远影/咒焰/回辉/祝言 可攻击**飞行**浊妖（对应参考 position=RANGED）。
- 索敌范围形状来自 `range_table.json` 归一化后的 43 种形状（方向型形状在
  引擎内以灯灵为中心镜像为对称覆盖；近战使用 plus4 十字邻域）。
- 数值平衡原则：物理伤害 = max(攻×10%, 攻−防)；咒术伤害 = 攻×100/(100+法抗)；
  ±8% 随机浮动。镇石靠 HP/阻挡，远影/咒焰靠射程与单点，疾风靠产油滚雪球。

## 3. 技能系统（21 个能力）

映射为原创能力。每职业 3 原型：`a` 被动（全★携带）+ `b`/`c` 主动（3★+ 携带），
数值按 ★ 分 low/mid/high 三档。灯灵 SP 0–100：时间/攻击/受击/击杀充能，
满费**自动释放**（单屏可玩，键鼠与触屏一致）。

## 4. 敌人与波次（关卡生成器）

敌种原型取自 `enemy_database.json` 的分类维度（地面/飞行 × 坦克/输出/术师/
召唤 × 普通/精英/首领，mass 强度分级），归一为 20 个原创浊妖：

- 基本：浊滴、墨蛙、腐鼠、骨兵、沙蛹、毒瘤兽、雾鸦(飞)、灯蛾(飞)
- 精英：铁壳蟹(重甲)、疾影鸦(迅捷)、蚀藤妖(再生)、唤俑师(召唤)、壳妖(护盾)、
  投岩妖(远程)、鬼武者(双高)、冥蝠(飞·远程)
- 首领：浊潮大将(召唤·坦)、渊影巫(远程AOE)、百目鬼(召唤·狂化)、灯蚀之主(终局)

波次构成参考 `stage_table.json` + 48 个主线关卡文件
（采样均值：2–3 分路 / 3.8 波 / 45.8 只 / 49 质量点）：

- **每局 18 关**（程序化生成）：关 n 的敌方质量预算 `B=10+5.5n+1.4n^1.25`，
  敌人属性 `×(1+0.14(n−1)+0.012(n−1)²)`（stage 18 ≈ ×7.1）。
- 分路布局 6 种模板（1/2/3 路，S 形/双路/三尾），按关卡索引分配：
  1–2 单路 → 3–4 双路/S 形 → 5–12 双路交错 → 13–18 三尾/复杂。
- **首领关：5 / 10 / 15 / 18**（对应 4 名首领，18 为终局首领，带阶段召唤+狂化）。
- 精英自第 4 关按 2%/关 概率混入（上限 28%）；波内刷怪 0.8–1.7s 间隔成组。

## 5. 肉鸽层（每局）

遗物/增益/事件体系参考 `roguelike_table.json`（190 遗物的 buff 类别分布 +
99 个 choice 事件 + 10 级 playerLevelTable 成长曲线），归一为：

- **28 件法器**（素/青/绯 三档，按 5:3:1.4 权重抽取，每关结束 3 选 1，
  灯焰 Lv.4/8 时 4 选 1）：开局灯油/生命、灯灵 HP/ATK/防御/法抗、
  伤害加成（物理/咒术/精英/首领/飞行）、灯油恢复与上限、充能速度、
  部署免费/减速敌、阻挡+1、波末治疗/护盾、灯心低于 30% 全体减伤、
  灯灵阵亡咒爆、击杀触发油等。
- **聚焰事件**（第 7、13 关）：淬炼灯灵(单灯+25%攻/生，限一次) /
  下关+150油 / 灯心回满 / 重摇最近法器。
- **灯焰等级**（参考 10 级经验曲线×10）：关 n 得 `12+2n` 经验；
  Lv.3/6/9 部署上限+1，Lv.4/8 法器选择+1。
- 部署上限 8（+元进度+灯焰+绯·千灯，上限 13）。

## 6. 元进度（跨局，localStorage）

- 通关每关得**残焰** `6+2n`（灯心余量≥80% +15 / ≥50% +8）。
- 百炼炉：解锁全部 42 灯灵（2★25 / 3★60 / 4★140 / 5★300 / 6★600 焰；
  初始解锁 7 名 1★ + 4 名 2★）；三条永久强化各 5 级
  （灯心+8 / 开局油+40 / 部署+1，逐级 40/80/150/260/420 焰）。
- 难度定位：无元进度 1–2★ 队约可至 8–12 关；完整 6★ 队 + 稳定法器可通 18。

## 7. 实现与操作

- 纯 HTML5 + Canvas 单页，无任何外部素材/字体/CDN；`js/data.js` 内嵌数据，
  `file://` 直开或任意静态托管（play worker 等）均可运行。
- 操作：点灯灵卡 → 点格子部署；点灯灵查看/撤收(返还80%)；点浊妖看情报。
  键盘：空格 暂停，1/2/3 速度，F 切职业页，R 撤收，M 静音，Esc/右键 取消。
  触屏：pointer 事件统一处理，卡片 ≥44px 热区。
- 数据管线：`python3 tools/normalize.py`（从仓库 6 张参考表归一化 →
  `game/data/*.json` + `game/js/data.js`，全量剥离原名）；
  `node tools/smoke.mjs`（无头自走对局，验证引擎与难度曲线）。
