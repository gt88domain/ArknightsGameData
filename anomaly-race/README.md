# 异变竞速 Anomaly Race

大富翁式环形地图 + 杀戮尖塔式卡牌战斗，**你（星晓）vs AI（夜阑）** 竞速解决异变：谁先击败最终 Boss「异变核心·蚀」谁获胜。

二次元风格 HTML5 网页游戏，双主角，无需构建，双击即玩。

## 运行

```bash
cd anomaly-race
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

或直接用浏览器打开 `index.html`（需联网加载字体，否则回退系统字体）。

## 玩法概览

- **环形地图**：掷骰移动，经过/落点触发格子（战斗/精英/商店/休息/事件/建筑/金币/宝库/Boss 门）。
- **卡牌战斗**：每回合 4 能量、抽 5 张，格挡每回合清空；易伤/虚弱/力量等状态；战后三选一拿牌。
- **竞速胜负**：你先击杀最终 Boss 即胜；夜阑先击杀则你败；你生命归零则败；夜阑归零则出局、但你仍须击杀 Boss。
- **轮次结构**：奇数轮 你→夜阑→Boss，偶数轮 夜阑→你→Boss；每轮双方各行动一次后 Boss 释放侵蚀脉冲（全场伤害，随轮次成长）。
- **异变核心**：第 7 轮后成型可挑战（此前到访领 30 金币调查经费）；落点/经过可停下挑战；第 7 轮起投骰前可用 **📡核心信标** 直达（代替移动）。
- **公平性**：双方地图/金币/建筑/卡牌/Boss 规则完全相同，共用同一套结算代码；AI 不能偷看未来随机数、未揭示奖励与你的牌组；标准以上难度 AI 的低阶遗物补偿在开局界面**公开**展示。

## AI 说明

- 夜阑每回合做完整决策：骰具选择、岔路、落点、战斗出牌、拿牌、商店、休息、精英/ Boss 挑战评估。
- Boss 挑战走可解释的 TTK/TTD 评估（速杀/坚守/背水一战），挑战胜率约 80%。
- AI 回合可 **4 倍加速 / 一键跳过**；AI 战斗同规则快速结算，只展示摘要（敌人/损失生命/金币/拿牌）。

## 测试

```bash
node test/sim.js      # 逻辑仿真：公平性不变量 + 全难度战斗 + 6 局 AI 对 AI 完整对局
node test/calib.js    # Boss 攻坚校准：5 套牌组 × 3 个轮次 × 25 场，验证挑战评估准确性
node test/smoke.js    # 浏览器冒烟测试（需 npm install jsdom）：真实页面自动游玩数轮
SEEDS=24 node test/sim.js   # 更多对局样本
```

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面骨架、开局界面、样式引用 |
| `data.js` | 数值配置：卡牌/遗物/敌人/Boss/地图/商店/事件 |
| `engine.js` | 规则引擎 + AI 决策（双方共用，保证公平） |
| `combat.js` | 卡牌战斗：玩家 UI / AI 快速结算 |
| `flow.js` | 落点结算：商店/休息/事件/招募/Boss 门 |
| `ui.js` | 棋盘渲染/移动/弹窗/音效 |
| `main.js` | 回合流程/Boss 行动/胜负/开局启动 |
| `assets/` | 立绘：player.png / rival.png / boss.png |
| `test/sim.js` | 无头仿真测试 |
| `test/calib.js` | Boss 攻坚校准 |
| `test/smoke.js` | 浏览器冒烟测试 |

## 设计备注

- 全局只有一条随机数流，种子决定一切；AI 思考不消耗随机数（`sim.js` 公平性测试覆盖）。
- 能量 4 / 起始生命 80 / Boss 125 + 2/轮，数值经校准脚本调定（见 `test/calib.js` 输出）。
